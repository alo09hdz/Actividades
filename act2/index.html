Anatomía Estructural del App Shell

Identificación visual de los elementos estáticos (Shell) frente al contenido hidratado dinámico

1. Header Estático (Persistente) Logo, estado online/offline, botón de instalación, perfil de usuario.
2. Menú de Navegación Escritorio: Barra lateral retraíble.
Móvil: Barra de pestañas inferior (Bottom Nav).
3. Contenedor Principal (Main Shell) Marco contenedor inmutable con rutas y estados.
4. Contenido Dinámico (Hydrated Data) Respuestas de API, datos y vistas que cargan de forma asíncrona mediante Skeleton Screens.

Cero Latencia Percibida

Al pulsar el icono de la PWA desde la pantalla de inicio, la Splash Screen nativa del SO oculta la inicialización y empalma de inmediato con el App Shell en caché.

Resiliencia Sin Conexión (Offline-First)

Incluso sin red móvil o WiFi, el usuario nunca verá la pantalla de error de dinosaurio de Chrome. La interfaz abre de inmediato con su estado visual intacto.

Eliminación de Saltos Visuales (CLS)

Al tener fijas las dimensiones del header y el menú, el Cumulative Layout Shift es 0, garantizando una calificación perfecta en Google Lighthouse.

Auditoría en Tiempo Real de Requisitos para Splash Screen

Validación automática de las propiedades del archivo manifest.json y el DOM actual

✓
Enlace al Web App Manifest <link rel="manifest" href="manifest.json">

Detectado en el <head> con ruta válida accesible por el navegador.

✓
Nombre de la Aplicación (name / short_name) "NexusShell"

Obligatorio para que Chromium renderice el texto debajo del icono durante el splash.

✓
Color de Fondo de la Splash Screen background_color: "#0a0f1d"

Pinta el lienzo completo de la pantalla mientras se inicializa el motor web del sistema.

✓
Color del Tema del Sistema (theme_color) theme_color: "#6366f1"

Tiñe la barra de estado nativa (batería, reloj, notificaciones) en Android y la barra de título en escritorio.

✓
Iconos de Alta Definición (192x192 & 512x512 maskable) icon-192x192.png | icon-512x512.png

Chromium centra automáticamente el icono de 512x512 (o 192x192) dentro del color de fondo.

✓
Modo de Visualización (display: standalone) display: "standalone"

Sin modo independiente o pantalla completa, Chrome abre la app como una pestaña web sin Splash Screen nativa.

✓
Service Worker Activo (Precacheo del App Shell) Registrado & Controlando

Requerido por el motor de instalación de Chrome para calificar como PWA instalable.

Procedimiento Oficial en Chrome DevTools

Pasos exactos para comprobar la Splash Screen y simular la instalación

01

Abrir Chrome DevTools

Presiona F12 o Ctrl + Shift + I en Google Chrome o Microsoft Edge.

02

Navegar a la Pestaña "Application" (Aplicación)

En la barra superior de DevTools, selecciona la pestaña Application (o despliega el menú » si está oculta).

03

Inspeccionar Sección "Manifest" & Ver la Splash Screen

En el panel izquierdo, haz clic en Manifest. Desplázate hacia abajo hasta la sección "Presentation" y "Icons": verás la vista previa exacta del icono y la previsualización de la Splash Screen generada por Chromium.

04

Simular la Instalación ("Install" o "Trigger Install")

En la esquina superior derecha del panel Manifest de DevTools, haz clic en el enlace "Install" o "Simulate install" para desencadenar el diálogo nativo de instalación en el escritorio/móvil.

05

Comprobar Persistencia Offline en "Service Workers"

Selecciona Service Workers en el panel izquierdo de DevTools y marca la casilla "Offline". Recarga la página (F5) para verificar que el App Shell carga instantáneamente desde el caché local.

Reglas de Generación Nativa de Splash en Android / Chromium

  • Lienzo del Fondo: Toma el valor exacto de background_color: "#0a0f1d".
  • Barra de Estado: Se colorea con theme_color: "#6366f1".
  • Icono Centrado: El navegador elige el icono de mayor resolución (512x512 px) y lo centra dentro de una máscara circular/cuadrada segura.
  • Texto Inferior: Se extrae de short_name (o name si falta).
  • Momento de Cierre: La Splash Screen desaparece automáticamente tan pronto como el App Shell emite su primer cuadro de pintura (First Contentful Paint).
