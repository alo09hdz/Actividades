Almacenamiento del App Shell en Evento Install

La arquitectura Cache-First intercepta cada solicitud estática en el Service Worker. Durante la fase de install, la Cache API descarga y persiste de forma atómica el HTML, CSS, JavaScript e imágenes base. En cada evento fetch posterior, el recurso se sirve directamente desde la memoria local con tiempos de respuesta menores a 5 ms.

Diagrama de Arquitectura y Ciclo de Vida

Cómo interactúan el evento install, la Cache API y el evento fetch en la PWA.

1

Evento 'install'

El navegador detecta el nuevo Service Worker. Se ejecuta event.waitUntil() para garantizar la instalación limpia.

caches.open(CACHE_NAME)
2

Precacheo del App Shell

Descarga atómica de todos los recursos esenciales (HTML, CSS, JS e imágenes base) hacia la memoria Cache Storage.

cache.addAll(STATIC_ASSETS)
3

Intercepción 'fetch'

Toda petición GET entrante es capturada por el Service Worker mediante event.respondWith().

caches.match(event.request)
4

Cache-First & Fallback

Si existe en caché (HIT), se devuelve en <5ms. Si no existe (MISS), se consulta la red (Network Fallback).

cachedResponse || fetch(req)

Guía de Verificación con Google Chrome DevTools

Comprueba el funcionamiento de la Cache API y el comportamiento offline paso a paso.

📱

1. Pestaña Application

  • Presiona F12 o Ctrl + Shift + I para abrir DevTools.
  • Selecciona la pestaña Application en el menú superior.
  • En el panel izquierdo, despliega Storage > Cache Storage.
  • Haz clic en appshell-cache-v1.0.0: observarás todos los recursos estáticos del App Shell (HTML, CSS, JS, PNG).
🌐

2. Pestaña Network (Red)

  • Abre la pestaña Network en DevTools.
  • Recarga la página con F5 o Ctrl + R.
  • En la columna Size, verifica que aparece (ServiceWorker) en lugar de bytes transferidos por red.
  • En la columna Time, confirma tiempos de respuesta ultrabajos (de 1 a 6 ms).
🔌

3. Prueba Offline Real

  • En la pestaña Network, localiza el selector de velocidad (por defecto No throttling).
  • Cámbialo a Offline.
  • Recarga la página completa con Ctrl + F5.
  • ¡Observa cómo la interfaz y todas las imágenes cargan instantáneamente sin conexión a internet gracias al App Shell en caché!
📟
